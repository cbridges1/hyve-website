<Warning>
  What this page used to call an "environment" — a named pointer to a local directory or hyve-api URL — is now a **context** (`hyve context`). "Environment" now means a scope within your organization on a hyve-api server. Both are explained in [Contexts & Environments](/docs/concepts/contexts).
</Warning>

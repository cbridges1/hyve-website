<Warning>
  `hyve env` has been renamed to [`hyve context`](/docs/cli/context). The subcommands are the same (`create`, `list`, `current`, `use`, `remove`, `path`, `login`, `logout`, `whoami`, `secrets`); only the group name changed, and `hyve context secrets` takes `--context` where it used to take `--env`.
</Warning>

## Why

"Environment" now means something else: a named scope within your organization on a hyve-api server, managed with [`hyve environment`](/docs/cli/environment). Your machine's pointer at a directory or server is a **context**. See [Contexts & Environments](/docs/concepts/contexts).

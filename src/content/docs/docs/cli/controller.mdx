Run hyve-controller on the management cluster (the chart runs it)

```text
  hyve controller [flags]
```

**Flags**

```text
      --admin-user string           hyve user who is cluster-admin on every child cluster (default "admin")
      --agent-image string          cattle-cluster-agent image (default "rancher/rancher-agent:v2.14.3")
      --agent-namespace string      namespace of the host's agent Secrets (default "hyve-system")
      --cert-dir string             where the webhook's generated certificate is written (default "/tmp/hyve-webhook")
      --fleet-image string          image for push delivery's fleet commands (default: the image fleet-controller runs)
  -h, --help                        help for controller
      --host-cacerts string         PEM CA the host's certificate chains to, when it isn't publicly trusted
      --host-url string             the hyve host's URL as child clusters reach it; installs cattle-cluster-agent on each cluster, pointed there
      --kubeconfig string           kubeconfig (default: in-cluster, or $KUBECONFIG)
      --lazy-providers              add known Cluster API providers when a ClusterClass or a Fleet bundle first needs them (local mode)
      --mutating-webhook string     MutatingWebhookConfiguration to patch the CA into (default "00-hyve-controller")
      --no-webhook                  run without the webhooks (templates then aren't filled in server-side)
      --service-name string         webhook Service name (default "hyve-controller")
      --service-namespace string    webhook Service namespace (default "hyve-system")
      --validating-webhook string   ValidatingWebhookConfiguration to patch the CA into (default "hyve-controller")
      --webhook-port int            webhook port (default 9443)
```

Opens hyve's web UI in the browser, signed in as you.

The UI is served by the host. The browser gets a session of its own, made
from the CLI's, so there's no password to type.

When the host's certificate comes from a CA the browser doesn't trust
(local mode's, or a private one given to 'hyve login --ca-cert'), the UI is
served through this command at http://127.0.0.1, which runs until Ctrl-C.

```text
  hyve ui [flags]
```

**Examples**

```text
  hyve ui
  hyve ui --server local
  hyve ui --no-browser   # print the URL instead
```

**Flags**

```text
  -h, --help            help for ui
      --no-browser      print the URL instead of opening a browser
      --port int        local port for serving a host the browser doesn't trust (0 picks one) (default 30445)
      --server string   saved server to open (default: the current one; see 'hyve context list')
```

Ends the session with a saved server. --forget also removes the server from
hyve's saved logins, which is the way to drop Rancher servers saved by older
versions of hyve.

```text
  hyve logout [flags]
```

**Flags**

```text
      --forget          also remove the server from the saved logins
  -h, --help            help for logout
      --server string   saved server to use (default: the one last signed in to)
```

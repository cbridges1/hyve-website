Installs Cluster API providers on the management cluster, through the
Cluster API Operator (or from release manifests in local mode). Variables are what the provider's clusterctl configuration reads:
credentials and feature flags.

```text
  hyve provider [command]
```

Aliases: `provider, providers`

**Flags**

```text
  -h, --help                help for provider
      --kubeconfig string   talk to a management cluster with this kubeconfig instead of a signed-in server (admins, CI)
      --server string       saved server to use (default: the current one; see 'hyve context list')
```

### hyve provider add

Install a Cluster API provider

```text
  hyve provider add NAME [flags]
```

**Examples**

```text
  hyve provider add docker --version v1.12.0
  hyve provider add gcp --variable-b64-file GCP_B64ENCODED_CREDENTIALS=./key.json --variable EXP_CAPG_GKE=true
  hyve provider add civo --fetch-url https://github.com/cbridges1/cluster-api-provider-civo/releases/latest/download/infrastructure-components.yaml \
      --variable CIVO_API_KEY
```

**Flags**

```text
      --fetch-url string                where to fetch the provider's components, for providers clusterctl doesn't know
  -h, --help                            help for add
      --namespace string                namespace (default: NAME-system)
      --provider-name string            clusterctl provider name, when it differs from NAME
      --type string                     infrastructure, bootstrap, controlPlane, core, addon, ipam, runtimeExtension (default "infrastructure")
      --variable stringArray            provider variable KEY=value, or KEY to read it from the environment (repeatable)
      --variable-b64-file stringArray   provider variable KEY=path, the file's contents base64-encoded (repeatable)
      --variable-file stringArray       provider variable KEY=path, the file's contents (repeatable)
      --version string                  provider version (default: the latest the installer knows)
```

### hyve provider remove

Uninstall a Cluster API provider (delete its clusters first)

```text
  hyve provider remove NAME [flags]
```

Aliases: `remove, rm`

**Flags**

```text
  -h, --help   help for remove
```

### hyve provider show

Show a Cluster API provider and its controller

```text
  hyve provider show NAME [flags]
```

**Flags**

```text
  -h, --help            help for show

```

Reads old hyve Templates (built with hyve-capi-module, hyve-civo-module or
hyve-unraid-k3s-module) and herd ClusterTemplates (herd.io), from YAML files
or from a cluster, and converts them into hyve ClusterTemplates: flavor
presets expanded, params mapped onto the ClusterClass, lockParams onto
locked variables, the schedule, and Helm and git resources as Fleet specs.
Prints them as YAML, or creates them in the template namespace with
--apply. What hyve can't express (workflows, other modules, locks on
non-variables) is listed on stderr.

--relabel-clusters (with --apply) also labels the clusters herd made from
each herd template with the new hyve.io/template labels, so they get the
template's resources and locks.

```text
  hyve import (-f FILE|DIR ... | --from-cluster) [flags]
```

**Examples**

```text
  hyve import -f ./templates                                # print
  hyve import --from-cluster --source-kubeconfig old.yaml --kubeconfig new.yaml --apply --relabel-clusters
```

**Flags**

```text
      --apply                       create the ClusterTemplates instead of printing them
  -f, --filename stringArray        file or directory of old hyve Templates or herd ClusterTemplates (repeatable)
      --from-cluster                read them from a cluster (see --source-kubeconfig)
  -h, --help                        help for import
      --kubeconfig string           talk to a management cluster with this kubeconfig instead of a signed-in server (admins, CI)
      --prefix-namespace            name every ClusterTemplate <old namespace>-<name>
      --relabel-clusters            with --apply, label clusters made from herd templates with the hyve.io/template labels
      --server string               saved server to use (default: the current one; see 'hyve context list')
      --source-context string       kubeconfig context for --from-cluster
      --source-kubeconfig string    kubeconfig for --from-cluster
      --source-namespace string     only this namespace's templates (default: all)
      --template-namespace string   namespace of templates and shared resources (default: the context's, or capi-clusters)
```

Installs hyve on the cluster your kubeconfig points at.

That's hyve-controller and hyve's host endpoint, the server users sign in
to and the child clusters' agents connect to (--host-url is where both
reach it), plus what's missing of cert-manager, the Cluster API Operator
with core Cluster API, and CAAPF (which installs Fleet).

A cluster that runs Rancher is refused unless --replace-rancher is given:
then Rancher, Turtles and herd are removed first (their charts, CRDs,
webhooks, namespaces and RBAC), while Fleet and Cluster API stay, with
their objects and running providers, which hyve then adopts. Rancher's
data (a PVC or host path) is left for you to delete. Take a backup first.

Run it as a cluster admin. Safe to re-run.

```text
  hyve install [flags]
```

**Examples**

```text
  hyve install --host-url https://hyve.example.com --host-tls-cert tls.crt --host-tls-key tls.key
  hyve install --replace-rancher --host-url https://hyve.example.com
```

**Flags**

```text
      --context string             kubeconfig context
  -h, --help                       help for install
      --host-cacerts string        PEM CA the host's certificate chains to, when it isn't publicly trusted
      --host-tls-cert string       certificate for the host to serve (default: plain HTTP, for a TLS-terminating proxy in front)
      --host-tls-key string        key for --host-tls-cert
      --host-url string            the host endpoint's URL, as users and child clusters reach it
      --image string               hyve image (default: the release's)
      --image-pull-policy string   image pull policy
      --kubeconfig string          kubeconfig for the management cluster (default: $KUBECONFIG or ~/.kube/config)
  -n, --namespace string           namespace for hyve (default "hyve-system")
      --only-hyve                  install hyve's chart only, not cert-manager, Cluster API, CAAPF or Fleet
      --replace-rancher            remove Rancher, Turtles and herd first, keeping Fleet and Cluster API
      --timeout duration           how long to wait (default 20m0s)
  -f, --values string              extra chart values (YAML)
```

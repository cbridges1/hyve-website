<Warning>
  `hyve set-state`/`hyve state` don't exist as commands. The functionality this page described — registering a local directory as hyve's active state directory, no git required — shipped as `hyve env create [--path]` / `hyve env use` / `hyve env current` instead. See the [`env` CLI reference](/docs/cli/env).
</Warning>

## What to use instead

```bash
hyve env create my-project --path ~/repos/my-project
hyve env use my-project
hyve env current
```

`hyve env` also covers what [`hyve git`](/docs/cli/git) used to (registering a directory), unified into one command group rather than two — see [Environments](/docs/concepts/repositories).

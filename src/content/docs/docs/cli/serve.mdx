<Warning>
  `hyve serve` and `hyve open` (and Hyve Studio, the browser UI that used them) have been removed. Their replacement is [cluster mode](/docs/concepts/cluster-mode): **hyve-api**, deployed with the controller from the Helm chart, serves the API *and* a built-in web console at the same address.
</Warning>

## What to use instead

- Deploy hyve-api and the controller — see [Deploying Cluster Mode](/docs/guides/deploying-cluster-mode).
- Open hyve-api's URL in a browser for the web console, or point the CLI at it with [`hyve context login`](/docs/cli/context).
- For a quick local instance, see [Cluster Patterns — host clusters locally](/docs/guides/cluster-patterns#3-creating-host-clusters-locally).

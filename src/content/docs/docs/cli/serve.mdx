<Warning>
  `hyve serve` (and `hyve open`) have been removed. Hyve no longer ships a REST/WebSocket API server, and Hyve Studio (the browser UI that talked to it) is unmaintained as a result.
</Warning>

## Why

The server surface added real, ongoing maintenance cost (its own auth-mode complexity, a REST/WebSocket API to keep in sync with every CLI command) for a UI-enablement feature that wasn't the CLI's core job. It was removed outright rather than kept around unmaintained.

## What still works

Everything the CLI already does directly against your state directory is unaffected — `hyve cluster`, `hyve reconcile`, `hyve workflow`, `hyve template`, `hyve module`, `hyve git`, and `hyve config` all work exactly as documented elsewhere in these docs. Nothing about local/git-backed usage changed.

## Related Commands

- [hyve config](/docs/cli/config) — read/write `hyve.yaml`, no server required
- [hyve git](/docs/cli/git) — repository management

Point Fleet at git repositories (plain Fleet GitRepos)

```text
  hyve repo [command]
```

Aliases: `repo, repos`

**Flags**

```text
  -h, --help                help for repo
      --kubeconfig string   talk to a management cluster with this kubeconfig instead of a signed-in server (admins, CI)
      --server string       saved server to use (default: the current one; see 'hyve context list')
```

### hyve repo add

Creates a Fleet GitRepo in a workspace. In fleet-local (the default) it
deploys to the management cluster itself. Fleet makes one bundle per
directory with a fleet.yaml under the given paths.

For a private repo give a username and a token, read from an environment
variable or a file; hyve keeps them in a basic-auth Secret the GitRepo uses.

```text
  hyve repo add NAME --repo URL [flags]
```

**Examples**

```text
  GIT_TOKEN=... hyve repo add nexus-config --repo https://github.com/org/nexus-config.git \
      --path fleet --username me --token-env GIT_TOKEN
```

**Flags**

```text
      --branch string       branch (default "main")
      --correct-drift       have Fleet undo changes made to what it deployed
  -h, --help                help for add
      --path stringArray    path in the repo (repeatable; default: the whole repo)
      --repo string         git repository URL (required)
      --token-env string    environment variable holding the git token
      --token-file string   file holding the git token
      --username string     git username for a private repo
      --workspace string    Fleet workspace (fleet-local is the management cluster; an environment namespace targets its clusters) (default "fleet-local")
```

### hyve repo remove

Delete a Fleet GitRepo; Fleet removes what it deployed

```text
  hyve repo remove NAME [flags]
```

Aliases: `remove, rm`

**Flags**

```text
  -h, --help               help for remove
      --workspace string   Fleet workspace (default "fleet-local")
```

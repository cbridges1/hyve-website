Reads ClusterTemplates, shared Resources and ClusterClasses from YAML files and
prints what hyve would create for a cluster made from the template: the
filled-in Cluster, and one Fleet object per resource. Nothing is contacted.
Without the ClusterClass among the files, its defaults (version, workers)
can't be filled in.

```text
  hyve render -f FILE... [--template NAME] [--name CLUSTER] [flags]
```

**Examples**

```text
  hyve render -f fleet/capi/templates/civo.yaml -f fleet/capi/classes/civo.yaml --name demo -e ci
```

**Flags**

```text
  -e, --env string             the cluster's environment (default "default")
  -f, --filename stringArray   YAML file with ClusterTemplates, Resources or ClusterClasses (repeatable)
  -h, --help                   help for render
      --name string            the cluster's name (default "example")
      --set stringArray        ClusterClass variable name=value (repeatable)
      --template string        which template, when the files hold several
```

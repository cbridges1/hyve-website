<Warning>
  `hyve config get`/`hyve config set` have been removed. `hyve.yaml` itself is still real and still read on every `hyve reconcile` — there's just no CLI command for it anymore. Edit it directly, like any other file in your state directory. See [Configuration](/docs/configuration).
</Warning>

## What to use instead

```bash
$EDITOR hyve.yaml
```

`hyve.yaml`'s shape (`reconcile.mode`, `reconcile.strictResourceDelete`, `env.file`) is unchanged — see [Configuration](/docs/configuration) for the full reference.

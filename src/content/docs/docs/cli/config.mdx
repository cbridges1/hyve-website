The `hyve config` command group reads and updates `hyve.yaml` at the root of your state repository.

## Commands

### hyve config get

Print the resolved `hyve.yaml` as YAML. If the file doesn't exist yet, prints the defaults hyve would otherwise fall back to.

```bash
hyve config get
```

**Example:**

```bash
hyve config get
```

**Output:**

```yaml
reconcile:
  mode: local
  strictDelete: false
  strictResourceDelete: false
env:
  file: local.env
```

---

### hyve config set

Set a single field in `hyve.yaml` by dotted key, save it, then commit and push — mirroring `PATCH /config`'s behavior exactly, including its soft-fail commit (a failed push is logged, not fatal — your local `hyve.yaml` is already updated and usable regardless).

```bash
hyve config set <key> <value>
```

<ParamField path="key" type="string" required>
  Dotted path to the field to set. See the supported keys below.
</ParamField>

<ParamField path="value" type="string" required>
  The new value. Booleans and integers are parsed from plain text (`true`/`false`, `8080`) — there's no separate `--type` flag.
</ParamField>

**Supported keys:**

| Key | Type | Description |
|-----|------|-------------|
| `env.file` | string | Path, relative to the repo root, to a local env file — see [Configuration](/docs/configuration#env-optional) |
| `reconcile.mode` | string | `local` or `cicd` |
| `reconcile.strictDelete` | bool | Warn about untracked cloud clusters |
| `reconcile.strictResourceDelete` | bool | Auto-prune orphaned `spec.resources` entries |

**Example:**

```bash
# Point reconciles/workflows at a local env file
hyve config set env.file local.env

# Switch to CI/CD mode
hyve config set reconcile.mode cicd
```

**Output:**

```
Set env.file = local.env
```

<Info>
  Setting `env.file` automatically appends it to `.gitignore` (idempotent — safe to run
  repeatedly, never duplicates an existing entry) before saving, so a locally-configured env
  file can't ship to your remote by omission. See [Configuration](/docs/configuration#env-optional).
</Info>

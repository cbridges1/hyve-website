### hyve host run

Runs hyve's host endpoint. Users sign in with a username and password
(hyve.io User objects; password hashes and sessions are Secrets in
--namespace), or through an OpenID Connect provider with --oidc-issuer
(the client secret comes from $HYVE_OIDC_CLIENT_SECRET), and the CLI and UI reach the management cluster through
/k8s/clusters/local as the signed-in user, impersonated as hyve:&lt;username&gt;.

On first start it creates the User "admin", with the password in the
--bootstrap-secret Secret's bootstrapPassword key (generated if the Secret
doesn't exist). The password must be changed at first sign-in.

Run it in the cluster it manages; it uses the in-cluster config, or
KUBECONFIG outside a cluster.

```text
  hyve host run [flags]
```

**Flags**

```text
      --audit-log                      write a JSON line to stdout for each request proxied to a cluster (user, groups, cluster, verb, path, status) (default true)
      --bootstrap-secret string        Secret holding the first admin's bootstrapPassword (default "bootstrap-secret")
      --cacerts string                 PEM CA the host's certificate chains to, for agents to pin (leave unset for a publicly trusted certificate)
  -h, --help                           help for run
      --listen string                  address to listen on (default ":8443")
      --local-user string              sign browsers at 127.0.0.1 or localhost in as this user without a password (local mode only: never on a host others can reach)
      --namespace string               namespace holding password and session Secrets (default: $POD_NAMESPACE or hyve-system) (default "hyve-system")
      --no-passwords                   turn password sign-in off, leaving single sign-in (the bootstrap admin then can't sign in)
      --oidc-allowed-domains strings   admit only verified emails in these domains
      --oidc-allowed-groups strings    admit only users in at least one of these groups
      --oidc-client-id string          the OIDC client ID
      --oidc-display-name string       the provider's name on the sign-in page ("Sign in with ...")
      --oidc-groups-claim string       the ID token claim holding the user's groups (default "groups")
      --oidc-issuer string             turns on single sign-in: the OpenID Connect issuer URL
      --oidc-scopes strings            scopes besides openid (default profile,email)
      --oidc-username-claim string     the ID token claim a new user's name comes from (then the email's local part) (default "preferred_username")
      --public-url string              the host's address as browsers reach it (needed for single sign-in's callback, and for the link in password-reset emails)
      --session-ttl duration           how long a sign-in lasts (default 16h0m0s)
      --shell-image string             image for the UI's kubectl shell (kubectl, helm, k9s; empty turns the shell off) (default "rancher/shell:v0.8.2")
      --smtp-from-address string       the From: address of hyve's emails (see --smtp-host)
      --smtp-from-name string          the From: name of hyve's emails (default "hyve"; see --smtp-host)
      --smtp-host string               SMTP relay for password resets and account emails, saved on first start only: after that the UI's Settings page owns it (the password comes from $HYVE_SMTP_PASSWORD)
      --smtp-port int                  the SMTP relay's port (see --smtp-host) (default 587)
      --smtp-tls                       implicit TLS, usually port 465; otherwise STARTTLS when offered (see --smtp-host)
      --smtp-username string           the SMTP relay's username; none for an anonymous relay (see --smtp-host)
      --tls-cert string                TLS certificate file (serves plain HTTP when unset, for use behind a TLS-terminating ingress)
      --tls-key string                 TLS key file
      --ui                             serve hyve's own UI at / (built into the binary with 'task ui')
```

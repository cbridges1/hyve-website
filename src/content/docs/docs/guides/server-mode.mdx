<Warning>
  The old server mode (`hyve serve`, its REST/WebSocket API, `hyve open`, and Hyve Studio) has been removed, along with every `hyve.yaml` `server.*` key. Its replacement is [cluster mode](/docs/concepts/cluster-mode) — hyve-controller plus hyve-api, deployed with the Helm chart, with a built-in web console served by hyve-api.
</Warning>
